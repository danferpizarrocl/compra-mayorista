# Compra Mayorista

App para armar la compra mayorista desde el celular: controla el monto disponible, compara con compras anteriores y exporta a Excel.

- No incluye datos personales: parte solo con la lista base de productos.
- Los datos se guardan en tu propio celular (no se envían a ningún servidor).
- Se puede instalar como app desde el navegador (Chrome: menú ⋮ → Instalar app).
